   621                                  ;***********************************************************************
   622                                  ; PS/2 mouse protocol (Standard PS/2 protocol)
   623                                  ;***********************************************************************
   624                                  ; ----------------------------------------------------------------------
   625                                  ;
   626                                  ; Data packet format: 
   627                                  ; Data packet is 3 byte packet. 
   628                                  ; It is send to the computer every time mouse state changes 
   629                                  ; (mouse moves or keys are pressed/released). 
   630                                  ; 
   631                                  ;   Bit7 Bit6 Bit5 Bit4 Bit3 Bit2 Bit1 Bit0 
   632                                  ; 
   633                                  ; 1. YO   XO   YS   XS   1    MB   RB   LB 
   634                                  ; 2. X7   X6   X5   X4   X3   X2   X1   X0
   635                                  ; 3. Y7   Y6   Y5   Y4   Y3   Y2   Y1   Y0
   636                                  ;
   637                                  ; This means:
   638                                  ; YO   :  Overflow bit for Y-coord (movement to fast)
   639                                  ; XO   :  Overflow bit for X-coord (movement to fast) 
   640                                  ; X0-X7:  byte of the x-coord 
   641                                  ; Y0-Y7:  byte of the y-coord
   642                                  ; LB   :  Left button pressed
   643                                  ; RB   :  Right button pressed
   644                                  ; MB   :  Middle button pressed
   645                                  ;
   646                                  ;*********************************************************************** 
   647                                  ;If you want to use the scroll function u might look up the protocol at 
   648                                  ;the company that made the mouse. 
   649                                  ;(the packet format will then mostly be greater then 3)
   650                                  ;***********************************************************************
